# 3D Phone Rotation Overlay (Gyroscope Support)

> **DISCLAIMER:** This project is created for **entertainment purposes only**.

A lightweight interactive web overlay that visualizes 3D phone rotation using device gyroscope sensors (`DeviceOrientationEvent`). Designed for high-performance rendering on mobile devices and responsive web browsers.

---

## Features

- **Real-Time Gyro Tracking:** Responds live to phone pitch, roll, and yaw (alpha, beta, gamma).
- **3D Interactive Overlay:** Renders a clean 3D phone model or visual frame over existing web content.
- **Lightweight & Fast:** Optimized for smooth performance on mobile browsers (Chrome, Safari, Kiwi, Edge).
- **Fallback Controls:** Drag-to-rotate interaction for desktop browsers without gyroscope hardware.
